# Grid Studio for Homebrew

```sh
brew tap adigold/gridstudio
brew trust adigold/gridstudio
brew install --cask grid-studio
```

[Grid Studio](https://github.com/adigold/GridStudio) turns a monome grid into a MIDI controller on macOS.

The app updates itself, so you do not need `brew upgrade` for it. To remove it and its settings: `brew uninstall --zap --cask grid-studio`.
